# Обновления ProjektBot

Подписанные клиентские пакеты для Windows x64. Для работы программы требуется действующая лицензия. Исходники, активатор администратора, ключи и лицензии клиентов здесь не публикуются.

Пакеты доступны в [разделе выпусков](https://github.com/Stanislav1710/ProjektBot-updates/releases).

## Подключение канала

В разделе обновлений программы включите «Загружать подписанные обновления без токена» и задайте:

- Адрес: `https://raw.githubusercontent.com/Stanislav1710/ProjektBot-updates/main/preview.pbotchannel.json`
- Канал: **Предварительный** (`preview`)
- Разрешённые серверы файлов, каждый с новой строки:

```text
github.com
release-assets.githubusercontent.com
objects.githubusercontent.com
```

Программа проверяет подпись списка выпусков и пакета, размер, хеш и номер выпуска перед подготовкой обновления. Скачивание не требует аккаунта GitHub или токена. Установка выполняется через существующий механизм обновлений программы.

Список выпусков имеет подписанный срок действия. Администратор обновляет его при публикации выпуска либо до истечения указанного в списке срока.
